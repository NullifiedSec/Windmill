# Roadmap

1. CLI catalog, tags and collections; scoring and tested persistence. (**first slice**)
2. Playback coordinator with MPD/mpv event state, queue, MPRIS and proper process cleanup.
3. Metadata/source model; YouTube and YouTube Music adapters, public browsing and search.
4. Downloads with progress, resumability, content deduplication and offline status.
5. Ratatui UI with navigable views, artwork and configurable collection/grouping views.
6. Lyrics: LRC parsing, LRCLIB metadata matching, synchronized side panel, configurable offset and cache.
7. Candidate discovery and locally explainable recommendation ranking; user feedback.
8. Operational checks, source-specific regressions, integrations and accessibility.

Do not promote the CLI to a mature media center until GUI/TUI, playback state and external integrations are tested on a real library.
